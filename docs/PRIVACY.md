# Privacy Policy

Effective date: 2026-01-04

## Overview

Browser Tab Counter is a Chrome extension that tracks the number of open tabs and aggregates counts into hourly, daily, weekly, and monthly summaries. The extension is designed to be lightweight and privacy-preserving.

## Data We Collect

- Tab count metrics (for example, current tab count and aggregated totals).
- Settings and preferences (for example, badge thresholds and whether messages are enabled).

## Data We Do Not Collect

- Browsing history, URLs, page content, or search queries.
- Personally identifiable information.
- Analytics or telemetry sent to external services.

## Where Data Is Stored

- All data is stored locally on the user's device using Chrome's `chrome.storage.local` API.
- No data is transmitted off the device by this extension.

## Data Retention

- Tab count data is retained on a rolling 90-day window.
- Older data is deleted automatically as new data is recorded.

## Data Sharing

- We do not sell, rent, or share your data with third parties.

## User Controls

- You can clear all stored data by removing the extension or clearing the extension's storage from Chrome's extension settings.

## Security

- The extension follows the principle of least privilege and only requests permissions needed to function (`tabs` and `storage`).

## Changes to This Policy

- If this policy changes, the updated policy will be published in this repository.
