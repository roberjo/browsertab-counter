This project is a Chrome Web Browser extension that tracks how many tabs the user keeps open at any one time. It collects stats on browser tabs opened per hour, per day averages.  It tracks stats by day, week, and month.
It awards badges for top ranking users who keep the most tabs open.
it gives funny messages when the user reaches certain numbers of tabs open.
10 tabs open - amateur hour
20 tabs open - okay software architect
30 tabs open - are you okay
>40 tabs open - you need help
This browser extension is meant to be light hearted and funny.
